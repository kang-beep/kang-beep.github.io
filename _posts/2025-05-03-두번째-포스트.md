# 마크다운 문법

이 포스트는 Jekyll 블로그에 새로운 포스트를 추가하는 방법을 보여주는 예시입니다.

## 마크다운(Markdown) 문법 완벽 가이드: 블로그 포스팅 쉽게 하기

안녕하세요\! Jekyll 블로그나 다른 여러 플랫폼에서 글을 작성할 때 매우 유용한 마크다운(Markdown) 문법에 대해 알아보겠습니다. 마크다운은 읽고 쓰기 쉬운 텍스트 형식으로, 몇 가지 간단한 기호만 알면 HTML 코드를 몰라도 웹 문서를 깔끔하게 작성할 수 있습니다.

아래는 여러분의 블로그 포스팅 예시에서 사용된 문법을 포함하여, 자주 사용되는 마크다운 문법들을 총정리한 내용입니다.

-----

### 1\. 제목 (Headings)

제목은 '\#' 기호로 표현합니다. '\#'의 개수에 따라 제목의 크기(수준)가 달라집니다. H1부터 H6까지 표현할 수 있습니다.

```markdown
# 이것은 H1 제목입니다

## 이것은 H2 제목입니다

### 이것은 H3 제목입니다

#### 이것은 H4 제목입니다

##### 이것은 H5 제목입니다

###### 이것은 H6 제목입니다
```

**결과:**

# 이것은 H1 제목입니다

## 이것은 H2 제목입니다

### 이것은 H3 제목입니다

#### 이것은 H4 제목입니다

##### 이것은 H5 제목입니다  

###### 이것은 H6 제목입니다  

-----

### 2\. 텍스트 강조 (Emphasis)

텍스트를 강조하는 방법에는 굵게(Bold)와 기울임(Italic)이 있습니다.  

  * **굵게**: 별표 두 개(`**`) 또는 밑줄 두 개(`__`)로 텍스트를 감싸세요.

    ```markdown
    **이 텍스트는 굵게 표시됩니다**
    __이 텍스트도 굵게 표시됩니다__
    ```

    **결과:** **이 텍스트는 굵게 표시됩니다**, **이 텍스트도 굵게 표시됩니다**

  * **기울임**: 별표 한 개(`*`) 또는 밑줄 한 개(`_`)로 텍스트를 감싸세요.

    ```markdown
    *이 텍스트는 기울임체로 표시됩니다*
    _이 텍스트도 기울임체로 표시됩니다_
    ```

    **결과:** *이 텍스트는 기울임체로 표시됩니다*, *이 텍스트도 기울임체로 표시됩니다*

  * **굵게 + 기울임**: 별표 세 개(`***`) 또는 밑줄 세 개(`___`)로 텍스트를 감싸세요.

    ```markdown
    ***이 텍스트는 굵게와 기울임체 모두 적용됩니다***
    ___이 텍스트도 굵게와 기울임체 모두 적용됩니다___
    ```

    **결과:** ***이 텍스트는 굵게와 기울임체 모두 적용됩니다***, ***이 텍스트도 굵게와 기울임체 모두 적용됩니다***

  * **취소선**: 물결표 두 개(`~~`)로 텍스트를 감싸세요.

    ```markdown
    ~~이 텍스트는 취소선이 적용됩니다~~
    ```

    **결과:** \~\~이 텍스트는 취소선이 적용됩니다\~\~

### 3\. 목록 (Lists)

순서가 없는 목록과 순서가 있는 목록을 만들 수 있습니다.

  * **순서 없는 목록**: 별표(`*`), 더하기(`+`), 또는 하이픈(`-`)을 사용하세요. 들여쓰기를 하면 하위 목록을 만들 수 있습니다.

    ```markdown
    - 첫 번째 항목
    - 두 번째 항목
      * 두 번째 항목의 하위 항목 1
      * 두 번째 항목의 하위 항목 2
    - 세 번째 항목
    ```

    **결과:**

      - 첫 번째 항목
      - 두 번째 항목
          * 두 번째 항목의 하위 항목 1
          * 두 번째 항목의 하위 항목 2
      - 세 번째 항목

  * **순서 있는 목록**: 숫자를 사용하고 점(`.`)을 찍으세요. 숫자는 꼭 순서대로 쓰지 않아도 자동으로 순서가 매겨집니다.

    ```markdown
    1. 첫 번째 항목
    2. 두 번째 항목
    1. 세 번째 항목 (숫자가 1이라도 자동으로 3으로 표시됨)
       1. 세 번째 항목의 하위 항목 1
       2. 세 번째 항목의 하위 항목 2
    ```

    **결과:**

    1.  첫 번째 항목
    2.  두 번째 항목
    3.  세 번째 항목 (숫자가 1이라도 자동으로 3으로 표시됨)
        1.  세 번째 항목의 하위 항목 1
        2.  세 번째 항목의 하위 항목 2

### 4\. 코드 (Code)

코드 조각이나 코드 블록을 표시할 수 있습니다.

  * **인라인 코드**: 백틱( \` ) 하나로 코드를 감싸세요. 문장 중간에 짧은 코드를 넣을 때 유용합니다.

    ```markdown
    파이썬에서 `print()` 함수는 출력을 위해 사용됩니다.
    ```

    **결과:** 파이썬에서 `print()` 함수는 출력을 위해 사용됩니다.

  * **코드 블록**: 백틱( \` ) 세 개로 코드 블록 전체를 감싸세요. 시작하는 백틱 뒤에 언어 이름을 명시하면 문법 강조(Syntax Highlighting)가 적용될 수 있습니다. (예시에서 Python 코드를 보여준 것처럼)

    ````markdown
    ```python
    def hello_world():
        print("Hello, World!")

    hello_world()
    ````

    ```javascript
    function greet(name) {
      console.log(`Hello, ${name}!`);
    }

    greet('Markdown');
    ```

    ````
    **결과:**

    ```python
    def hello_world():
        print("Hello, World!")

    hello_world()
    ````

    ```javascript
    function greet(name) {
      console.log(`Hello, ${name}!`);
    }

    greet('Markdown');
    ```

### 5\. 링크 (Links)

웹 페이지나 다른 문서로 연결되는 링크를 만들 수 있습니다.

```markdown
[표시될 텍스트](URL "링크에 마우스를 올렸을 때 나타나는 설명 - 생략 가능")
```

**예시:**

```markdown
[Google](https://www.google.com)
[네이버](https://www.naver.com "네이버 홈페이지로 이동")
```

**결과:**

[Google](https://www.google.com)
[네이버](https://www.naver.com "네이버 홈페이지로 이동")

### 6\. 이미지 (Images)

이미지를 삽입하는 방법은 링크와 비슷하지만 앞에 느낌표(`!`)를 붙입니다.

```markdown
![이미지 설명(Alt Text)](/경로/이미지파일.jpg "이미지에 마우스를 올렸을 때 나타나는 설명 - 생략 가능")
```

**예시:**

```markdown
![Jekyll 로고](/assets/img/jekyll.jpg "Jekyll 로고 이미지")
```

**결과:** 
![Jekyll 로고](/assets/img/jekyll.jpg "Jekyll 로고 이미지")

**참고:** 예시 포스트에서는 `<img src="/assets/img/jekyll.jpg" alt="이미지 설명" style="width: 70%; max-width: 800px; height: auto; display: block; margin: 0;">` 와 같이 HTML 태그를 직접 사용했습니다. 마크다운 표준 문법만으로는 이미지 크기나 스타일을 직접 조절하기 어렵기 때문에, 세밀한 제어가 필요할 때는 이렇게 HTML 태그를 혼용할 수 있습니다.

### 7\. 인용문 (Blockquotes)

다른 사람의 말이나 문서를 인용할 때는 꺾쇠괄호(`>`)를 사용합니다.

```markdown
> 이것은 인용문입니다.
> 여러 줄에 걸쳐 작성할 수 있습니다.
>
> > 중첩된 인용문도 만들 수 있습니다.
```

**결과:**

> 이것은 인용문입니다.
> 여러 줄에 걸쳐 작성할 수 있습니다.
>
> > 중첩된 인용문도 만들 수 있습니다.

-----

### 8\. 수평선 (Horizontal Rules)

문단을 나누거나 시각적인 구분을 위해 수평선을 넣을 수 있습니다. 하이픈(`-`), 별표(`*`), 또는 밑줄(`_`)을 세 개 이상 연속으로 사용하면 됩니다.

```markdown
---
***
___
```

### 9\. 특수 문자 이스케이프 (Escaping Characters)

마크다운 문법에 사용되는 특수 문자(`*`, `#`, `\` 등)를 문법이 아닌 일반 문자로 표시하고 싶을 때는 해당 문자 앞에 백슬래시(`\`)를 붙여주면 됩니다.

```markdown
\*이것은 기울임체가 아니라 별표로 시작하는 텍스트입니다.\*
\# 이것은 제목이 아니라 샵 기호로 시작하는 텍스트입니다.
```

**결과:**

\*이것은 기울임체가 아니라 별표로 시작하는 텍스트입니다.\*
\# 이것은 제목이 아니라 샵 기호로 시작하는 텍스트입니다.
