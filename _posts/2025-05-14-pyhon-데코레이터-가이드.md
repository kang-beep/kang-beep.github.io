## 1. 클로저: 기억하는 함수

클로저는 '기억력이 있는 함수'라고 생각하면 쉽습니다. 함수가 만들어진 환경의 변수를 기억하고 나중에도 사용할 수 있는 특별한 함수입니다.

### 클로저의 핵심 요소

1. 함수 안에 또 다른 함수가 있어야 합니다(중첩 함수).
2. 내부 함수가 외부 함수의 변수를 사용해야 합니다.
3. 외부 함수는 내부 함수를 반환해야 합니다.

### 클로저 예시: 인사말 생성기

```python
def 인사말_만들기(이름):
    인사_메시지 = f"안녕하세요, {이름}님!"  # 외부 함수의 변수
    
    def 인사하기():
        return 인사_메시지  # 외부 함수의 변수를 사용
    
    return 인사하기  # 내부 함수 반환

# 클로저 생성하기
홍길동_인사 = 인사말_만들기("홍길동")
김철수_인사 = 인사말_만들기("김철수")

# 나중에 사용하기
print(홍길동_인사())  # 출력: 안녕하세요, 홍길동님!
print(김철수_인사())  # 출력: 안녕하세요, 김철수님!
```

위 예시에서 `인사하기` 함수는 `인사말_만들기` 함수가 실행을 마친 후에도 `이름` 변수의 값을 기억합니다. 마치 편지를 봉투에 넣어 보관하는 것처럼, 클로저는 데이터를 함수와 함께 "봉인"합니다.

### 클로저의 실용적 예시: 카운터

```python
def 카운터_만들기():
    횟수 = 0  # 외부에서 직접 접근할 수 없는 변수
    
    def 카운트():
        nonlocal 횟수  # 외부 함수의 변수를 수정하기 위한 선언
        횟수 += 1
        return 횟수
    
    return 카운트

내_카운터 = 카운터_만들기()
print(내_카운터())  # 1
print(내_카운터())  # 2
print(내_카운터())  # 3
```

이 예시는 외부에서 직접 접근할 수 없는 '비공개' 변수를 만드는 방법을 보여줍니다. `횟수` 변수는 오직 `카운트` 함수를 통해서만 접근하고 수정할 수 있습니다.

## 2. 래퍼 함수: 감싸는 함수

래퍼 함수는 다른 함수를 '감싸는' 함수입니다. 선물을 포장하듯이, 원래 함수에 추가 기능을 덧붙일 수 있습니다.

### 래퍼 함수 예시: 실행 시간 측정하기

```python
def 시간_측정(원래_함수):
    import time
    
    def 래퍼():
        시작_시간 = time.time()  # 함수 실행 전 작업
        결과 = 원래_함수()       # 원래 함수 실행
        종료_시간 = time.time()  # 함수 실행 후 작업
        print(f"함수 실행 시간: {종료_시간 - 시작_시간}초")
        return 결과
    
    return 래퍼

def 오래_걸리는_작업():
    import time
    time.sleep(2)  # 2초 동안 멈춤
    return "작업 완료!"

# 함수 감싸기
측정된_작업 = 시간_측정(오래_걸리는_작업)

# 실행하기
결과 = 측정된_작업()  # "함수 실행 시간: 2.xxx초" 출력
print(결과)  # "작업 완료!" 출력
```

이 예시에서 `시간_측정` 함수는 다른 함수를 인자로 받아, 그 함수의 실행 시간을 측정하는 기능을 추가한 새로운 함수를 반환합니다.

### 인자가 있는 함수 래핑하기

```python
def 시간_측정(원래_함수):
    import time
    
    def 래퍼(*args, **kwargs):  # 모든 종류의 인자를 받을 수 있음
        시작_시간 = time.time()
        결과 = 원래_함수(*args, **kwargs)  # 원래 함수에 인자 전달
        종료_시간 = time.time()
        print(f"함수 실행 시간: {종료_시간 - 시작_시간}초")
        return 결과
    
    return 래퍼

def 인사하기(이름):
    import time
    time.sleep(1)
    return f"안녕하세요, {이름}님!"

# 함수 감싸기
측정된_인사 = 시간_측정(인사하기)

# 인자와 함께 호출
결과 = 측정된_인사("홍길동")  # "함수 실행 시간: 1.xxx초" 출력
print(결과)  # "안녕하세요, 홍길동님!" 출력
```

`*args`와 `**kwargs`를 사용하면 어떤 종류의 인자라도 원래 함수에 전달할 수 있습니다.

## 3. 데코레이터: 장식하는 문법

데코레이터는 래퍼 함수를 더 쉽게 사용할 수 있는 파이썬의 특별한 문법입니다. `@` 기호를 사용하여 함수나 클래스에 "장식"을 추가합니다.

### 기본 데코레이터

```python
def 시간_측정(함수):
    import time
    
    def 래퍼(*args, **kwargs):
        시작_시간 = time.time()
        결과 = 함수(*args, **kwargs)
        종료_시간 = time.time()
        print(f"함수 실행 시간: {종료_시간 - 시작_시간}초")
        return 결과
    
    return 래퍼

# 데코레이터 사용하기
@시간_측정
def 오래_걸리는_작업():
    import time
    time.sleep(2)
    return "작업 완료!"

# 직접 호출하기
결과 = 오래_걸리는_작업()  # 자동으로 시간 측정됨
print(결과)  # "작업 완료!" 출력
```

`@시간_측정` 구문은 `오래_걸리는_작업 = 시간_측정(오래_걸리는_작업)`과 정확히 같은 의미입니다. 하지만 훨씬 더 읽기 쉽고 의도가 명확합니다.

### 데코레이터에 인자 전달하기

```python
def 반복(횟수):
    def 데코레이터(함수):
        def 래퍼(*args, **kwargs):
            결과 = None
            for _ in range(횟수):
                결과 = 함수(*args, **kwargs)
            return 결과
        return 래퍼
    return 데코레이터

@반복(3)
def 인사하기(이름):
    print(f"안녕하세요, {이름}님!")
    return "인사 완료"

인사하기("홍길동")  
# 안녕하세요, 홍길동님!
# 안녕하세요, 홍길동님!
# 안녕하세요, 홍길동님!
```

이 예시는 데코레이터에 인자를 전달하는 방법을 보여줍니다. `@반복(3)`은 함수를 세 번 반복 실행하는 데코레이터를 만듭니다.

### 여러 데코레이터 중첩하기

```python
def 굵게(함수):
    def 래퍼(*args, **kwargs):
        return f"<b>{함수(*args, **kwargs)}</b>"
    return 래퍼

def 기울임(함수):
    def 래퍼(*args, **kwargs):
        return f"<i>{함수(*args, **kwargs)}</i>"
    return 래퍼

@굵게
@기울임
def 인사하기(이름):
    return f"안녕하세요, {이름}님!"

print(인사하기("홍길동"))  # <b><i>안녕하세요, 홍길동님!</i></b>
```

데코레이터는 위에서 아래로 적용됩니다. 위 예시에서는 먼저 `기울임`이 적용된 후, `굵게`가 적용됩니다.

## 4. 실제 활용 사례

### 1) 로그인 확인 데코레이터

```python
def 로그인_필요(함수):
    def 래퍼(사용자, *args, **kwargs):
        if 사용자.로그인_상태:
            return 함수(사용자, *args, **kwargs)
        else:
            return "먼저 로그인해주세요!"
    return 래퍼

class 사용자:
    def __init__(self, 이름):
        self.이름 = 이름
        self.로그인_상태 = False
    
    def 로그인(self):
        self.로그인_상태 = True
        return f"{self.이름}님이 로그인했습니다."
    
    @로그인_필요
    def 프로필_보기(self):
        return f"프로필: {self.이름}님의 정보입니다."

# 사용 예시
홍길동 = 사용자("홍길동")
print(홍길동.프로필_보기())  # "먼저 로그인해주세요!"
print(홍길동.로그인())       # "홍길동님이 로그인했습니다."
print(홍길동.프로필_보기())  # "프로필: 홍길동님의 정보입니다."
```

이 예시는 사용자가 로그인했는지 확인하는 데코레이터를 보여줍니다. 웹 애플리케이션에서 특정 페이지에 접근하기 전에 로그인을 확인하는 용도로 자주 사용됩니다.

### 2) Flask 웹 프레임워크의 라우팅

```python
from flask import Flask
app = Flask(__name__)

@app.route('/')
def 홈페이지():
    return '환영합니다!'

@app.route('/about')
def 소개페이지():
    return '저희 웹사이트 소개입니다.'
```

Flask에서는 데코레이터를 사용하여 URL 경로와 함수를 연결합니다. `@app.route('/')`는 루트 URL('/')로 요청이 들어오면 `홈페이지` 함수를 실행하라는 의미입니다.

### 3) Python의 내장 데코레이터

```python
class 온도변환:
    def __init__(self, 섭씨):
        self._섭씨 = 섭씨
    
    @property
    def 섭씨(self):
        return self._섭씨
    
    @property
    def 화씨(self):
        return self._섭씨 * 9/5 + 32
    
    @섭씨.setter
    def 섭씨(self, 값):
        if 값 < -273.15:
            raise ValueError("절대 영도보다 낮을 수 없습니다!")
        self._섭씨 = 값

# 사용 예시
온도 = 온도변환(25)
print(온도.섭씨)  # 25
print(온도.화씨)  # 77.0
온도.섭씨 = 30
print(온도.화씨)  # 86.0
```

`@property` 데코레이터는 메서드를 속성처럼 사용할 수 있게 해줍니다. 이를 통해 값을 읽거나 설정할 때 추가 로직(예: 유효성 검사)을 실행할 수 있습니다.

### 4) 데이터 클래스

```python
from dataclasses import dataclass

@dataclass
class 학생:
    이름: str
    나이: int
    학년: int

홍길동 = 학생("홍길동", 15, 1)
print(홍길동)  # 학생(이름='홍길동', 나이=15, 학년=1)
```

`@dataclass` 데코레이터는 클래스에 필요한 특수 메서드(`__init__`, `__repr__` 등)를 자동으로 생성해줍니다.

## 5. 이런 개념들을 왜 사용해야 할까요?

### 코드 중복 제거

데코레이터를 사용하면 여러 함수에 동일한 코드를 반복해서 작성할 필요가 없습니다.

**데코레이터 없이:**
```python
def 함수1():
    # 권한 검사
    if not 사용자.권한_있음():
        return "권한이 없습니다"
    # 실제 함수 내용...

def 함수2():
    # 권한 검사 (중복 코드)
    if not 사용자.권한_있음():
        return "권한이 없습니다"
    # 실제 함수 내용...
```

**데코레이터 사용:**
```python
def 권한_필요(함수):
    def 래퍼(*args, **kwargs):
        if not 사용자.권한_있음():
            return "권한이 없습니다"
        return 함수(*args, **kwargs)
    return 래퍼

@권한_필요
def 함수1():
    # 실제 함수 내용...

@권한_필요
def 함수2():
    # 실제 함수 내용...
```

### 관심사 분리

데코레이터를 사용하면 핵심 기능과 부가 기능을 분리할 수 있습니다. 이렇게 하면 코드가 더 깔끔해지고 각 부분이 한 가지 일만 처리하게 됩니다.

```python
@로깅
@시간_측정
@권한_검사
def 중요_기능():
    # 핵심 로직만 포함
    pass
```

### 유연한 기능 확장

클로저와 데코레이터를 사용하면 기존 코드를 수정하지 않고도 새로운 기능을 추가할 수 있습니다. 이는 "개방-폐쇄 원칙"(확장에는 열려 있고, 수정에는 닫혀 있어야 한다)을 따르는 것입니다.

### 가독성 향상

잘 설계된, 이름이 명확한 데코레이터는 코드의 의도를 더 명확하게 표현할 수 있습니다.

```python
@캐시
@비동기
@재시도(최대_시도=3)
def 데이터_가져오기(id):
    # ...
```

위 코드는 이 함수가 캐싱을 사용하고, 비동기적으로 실행되며, 실패 시 최대 3번까지 재시도한다는 것을 한눈에 알 수 있게 해줍니다.

### 코드 재사용성

클로저와 데코레이터는 코드 재사용성을 크게 높여줍니다. 한 번 작성한 데코레이터는 프로젝트 전체에서 필요할 때마다 사용할 수 있습니다.

### 유지보수성 향상

공통 기능을 데코레이터로 분리하면 그 기능을 변경해야 할 때 한 곳만 수정하면 됩니다. 이는 유지보수를 훨씬 쉽게 만들어 줍니다.

## 결론

클로저, 래퍼 함수, 데코레이터는 파이썬 프로그래밍에서 코드를 더 깔끔하고 효율적으로 작성할 수 있게 해주는 강력한 도구입니다. 처음에는 이해하기 어려울 수 있지만, 이 개념들을 마스터하면 코드의 품질과 가독성을 크게 향상시킬 수 있습니다.

요약하자면:
- **클로저**: 함수가 만들어질 때의 환경을 기억하는 함수
- **래퍼 함수**: 다른 함수를 감싸서 기능을 추가하는 함수
- **데코레이터**: 래퍼 함수를 더 쉽게 사용할 수 있는 특별한 문법
